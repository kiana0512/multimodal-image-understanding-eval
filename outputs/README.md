# Outputs

Runtime outputs are written here and ignored by git except this file and `.gitkeep`.

Recommended layout:

```text
outputs/features/
outputs/retrieval/
outputs/quality_eval/
outputs/segmentation_eval/
outputs/classification/
outputs/reports/
outputs/figures/
```

All included result examples should be treated as `placeholder`, `demo result`, `not yet run`, or `example output` unless backed by real experiment logs.
