# Toy Images

Put a few small `.jpg` / `.png` files here for local pipeline tests:

```text
data/toy_images/
  cat_001.jpg
  dog_001.jpg
  sword_icon_001.png
  character_001.png
```

You can also run:

```bash
python scripts/create_toy_placeholders.py
```

The generated images are pure-color placeholders with text labels. They are only for testing the code path and do not represent real experimental data.
